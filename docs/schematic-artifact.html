Sheet 1 — Power input & LM2596 buck (12/24V → 5V)

RA-1–01 · Rev A
  • Q1 gate bias. R1 pulls the gate toward GND relative to source, holding the P-MOSFET on under normal (correct) polarity; on a reverse connection the channel stays off. For 24V systems, consider adding a 15V zener from gate to source to clamp Vgs.
  • D1 TVS selection. Use a 33V-clamp part (e.g. SMBJ33A) on 24V systems, or an 18V part on 12V-only systems — size it to survive alternator load-dump without clamping normal operating voltage.
  • L1 selection. Pick inductance from the LM2596 datasheet's Vin/Vout/Iload chart; use a shielded type to limit radiated EMI near the analog front end on Sheet 4.
  • U1 package note. Confirm exact pin numbering against the datasheet for your chosen package (TO-220-5 IC vs. a drop-in module).

Sheet 2 — AMS1117-3.3 LDO & rail distribution (5V → 3.3V)

RA-1–02 · Rev A
  • Why not run the LM2596 straight to 3.3V? The AMS1117's high PSRR filters the buck's switching ripple before it reaches the 16-bit ADC reference — important given the sub-mV resolution you're after.
  • Thermal. At ~0.5A total 3.3V load, U2 dissipates roughly (5V−3.3V)×0.5A ≈ 0.85W — give the SOT-223 tab copper pour, don't bury it under other parts.

Sheet 3 — ESP32-C3 module

RA-1–03 · Rev A
  • Bare module vs. devkit. A bare ESP32-C3 module needs the full decoupling/strapping shown; a devkit already has most of this on-board — feed its 3V3 pin directly from Sheet 2 and skip R2/C9/R3 if so.
  • ALERT/RDY. Wiring the ADS1115's ALERT pin to a spare GPIO lets firmware wait on conversion-ready via interrupt instead of a fixed polling delay across 4 channels.

Sheet 4 — ADS1115 & sensor interface

RA-1–04 · Rev A
  • Gain. Set the ADS1115 PGA to ±4.096V (gain=1) on every channel — comfortably covers 0–3.3V with ~125µV/step resolution.
  • Mux settling. Discard the first conversion after each channel switch; the ADS1115 has one ADC core behind a single mux.
  • J2 wiring is the key design choice. If a 5-conductor run to the sensor isn't practical, AIN2/AIN3 can instead tap the local 3.3V rail and local GND at the enclosure — still catches regulator drift, but not cable drop.
  • Cable practice. Twisted pair per signal+return, overall shield grounded at the electronics end only, routed clear of the LM2596 switching loop on Sheet 1.
